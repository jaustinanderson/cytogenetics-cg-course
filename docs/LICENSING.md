# Licensing

## Current status

No repository-wide license has been selected. Until Austin explicitly chooses
licenses, default copyright rules apply to the original software and
educational content.

This is deliberate. The repository contains different rights categories:

1. software code
2. original educational prose, questions, and diagrams
3. third-party public-domain media (the two embedded course images)
4. third-party separately licensed media under its own license (the
   self-hosted IBM Plex Sans/Mono webfonts, SIL Open Font License 1.1)
5. names and marks used descriptively

A single software license should not silently determine the treatment of all
five.

## Candidate future structure

- Software: MIT or another Austin-approved software license
- Original educational content: an Austin-selected Creative Commons license or
  reserved rights
- Third-party media: excluded from the project license and governed by its
  individual source record

No license should be added until that split is explicit.

## Third-party material

See [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md). Public-domain media
does not become covered by a future project license merely because it is
displayed by the course.

As of 2026-07-31 this also includes the self-hosted IBM Plex Sans and IBM
Plex Mono webfonts (`assets/fonts/`), which are separately licensed under
the SIL Open Font License, Version 1.1 (full text committed alongside the
font files) rather than public domain. The OFL governs the font files
themselves independently of any future project license: it already permits
this repository's use (bundling/embedding/redistribution with software), it
does not require this repository to adopt any particular license itself, and
a future software license chosen for this repository's own code would not
retroactively relicense the font files, which remain OFL-licensed IBM Plex
files regardless.
