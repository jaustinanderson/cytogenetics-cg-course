# Licensing

## Current status

No repository-wide license has been selected. Until Austin explicitly chooses
licenses, default copyright rules apply to the original software and
educational content.

This is deliberate. The repository contains different rights categories:

1. software code
2. original educational prose, questions, and diagrams
3. third-party public-domain or separately licensed media
4. names and marks used descriptively

A single software license should not silently determine the treatment of all
four.

## Candidate future structure

- Software: MIT or another Austin-approved software license
- Original educational content: an Austin-selected Creative Commons license or
  reserved rights
- Third-party media: excluded from the project license and governed by its
  individual source record

No license should be added until that split is explicit.

## Third-party material

See [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md). Public-domain media
does not become covered by a future project license merely because it is
displayed by the course.

## Marks

ASCP and credential designations are referenced only to describe exam
alignment. This independent project is not affiliated with, endorsed by, or
sponsored by ASCP or the ASCP Board of Certification.
